About this prototype

    
TIFFscope aims to connect the logical tile/strip layout of TIFF and GeoTIFF images to their physical storage and structural diagnostics.

    
Current limitation: This demonstration uses synthetic metadata. It does not yet parse uploaded TIFF files or use OCaml-TIFF to extract metadata.
